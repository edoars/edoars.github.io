# Icons

Unmodified SVGs, inlined by the `icon` component in `templates/components/icon.html`.

| Directory       | Source                                                                                | Version | License    |
| --------------- | ------------------------------------------------------------------------------------- | ------- | ---------- |
| `simple-icons/` | [Simple Icons](https://github.com/simple-icons/simple-icons)                          | 13.21.0 | CC0-1.0    |
| `material/`     | [Material Design Icons](https://github.com/marella/material-design-icons) (`filled/`) | 0.14.15 | Apache-2.0 |

Simple Icons is pinned to 13.21.0 because LinkedIn was removed in 14.0.0.

To add or update one, download it from jsDelivr, e.g.
`https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/github.svg`.
